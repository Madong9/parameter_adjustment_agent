## 通用动作还可以改进的地方

1. **按阶段进展设计信号。** 优先提供任务相关的密集信号，再逐步增加精度和运动质量要求；避免仅用最终成功奖励、或用全程稳定性压制起跳/翻转。侧翻目前使用完整动作学习阶段与接触门控，尚未加入“先单独学起跳、再学旋转、最后学恢复”的分步预训练。
2. **用真实分布调权。** 对每项记录原始值、加权贡献和启用比例，依据 PPO 数据检查某项是否长期为零、是否占据总奖励或被正值裁剪抵消。静态权重上限只能发现明显异常，不能保证不同物理量已经平衡。
3. **加强投机反例。** 用原地不动、身体拖地、仅绕 yaw 旋转、连续翻转、短暂触发后立即失稳等反例验证奖励。当前新增测试覆盖旋转轴、初始站立冒充落地、零命令、回合状态和课程执行；仍需真实仿真中的连续翻转、蹭地和接触噪声检查。
4. **检查采集能力和时间精度。** 对通用动作逐项核对指标来源、单位、坐标系、动作窗口与采样频率。短腾空动作的验收最好使用控制步轨迹，而不只使用视频帧采样。
5. **以证据诊断可恢复性。** 少量探索未成功应报告“当前方案/预算未收敛”，不能直接推断动作物理不可行。继续训练前应先证明奖励方向、激活窗口和终止条件一致，预算扩展须另行明确。
