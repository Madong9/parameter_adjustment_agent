# 安全边界

- 仅自动化仿真训练和评估。任何路径都不会调用 `deploy_real`，也不会向实体机器人发送命令。
- 生产推理只能通过 OpenCLI 和 ChatGPT 网页完成，不依赖 OpenAI SDK、模型 API 或 API Key。
- 训练与 rollout 命令均使用参数数组构造并通过 `shell=False` 执行；不存在通用命令执行接口。
- 上位机默认只监听 `127.0.0.1`，其训练请求限制大小，并对机器人和模式执行服务端白名单校验；静态资源使用固定路由。
- 实验、配置和 checkpoint 路径必须位于允许根目录内，任何 `..` 逃逸都会被拒绝。
- 不删除或覆盖原始机器人配置和 checkpoint；生成配置保存在独立候选目录。
- 进程不使用 sudo，均有超时、stdout/stderr/PID/退出状态记录，并按进程组终止。
- 生成奖励源码必须通过 AST 限制和张量冒烟测试。
- 硬约束覆盖有限值、关节/扭矩限制、禁止接触、摔倒和异常终止。视觉与数值冲突必须人工审核。
- Sim-to-Real 只能产生建议报告。实机部署位于本 Agent 之外，必须获得独立、明确的人工批准。
- 浏览器状态检查会识别登录失效和验证码；这些情况绝不会被误判为模型成功回复。
