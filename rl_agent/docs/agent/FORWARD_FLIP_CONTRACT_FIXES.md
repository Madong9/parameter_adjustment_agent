## 旋转与独立验收

utils/rotation.py 采用相邻控制步的 xyzw 四元数最短旋转向量，参考坐标为前一机体。正向 body_y 为前翻，四元数正负表示与初始航向不改变判断，避免直接累计欧拉 pitch 的回绕。顺序和乘法约定参考 [NVIDIA IsaacGymEnvs 四元数工具](https://github.com/isaac-sim/IsaacGymEnvs/blob/main/isaacgymenvs/utils/torch_jit_utils.py)。NumPy 与 Torch 实现用解析轨迹交叉验证；相邻旋转超过 90 度为本实现的欠采样边界，保持未知。

| 接口 | 行为 |
| --- | --- |
| net_pitch_progress | 从全足支撑开始，只累计首个有效腾空动作及离地/首次落地边界的正向横轴净旋转；正收益随历史最高进度增加并封顶，倒退扣分，重复起跳不叠加 |
| pitch_rotation | 腾空时跟踪正向横轴角速度，同时抑制其他轴角速度 |
| front_flip_recovery | 首个动作完成净旋转目标后，才奖励全足支撑、低姿态误差与低速度；初始站立不贡献完成分 |
| final_pitch_angle | 独立从轨迹四元数计算有符号横轴旋转；后翻保持负值，不取绝对值 |
| pitch_axis_error | 同一区间的非横轴旋转长度/总旋转长度，侧翻和转向不能冒充前翻 |

多个奖励每个控制步共用一次状态更新；每个环境的 episode 重置独立清理。没有起跳来源、出现多个动作起跳、未落地时完成角度为零；姿态缺失、无效、重置、时间异常或旋转欠采样时保持未知，不用普通 pitch 角补齐。

前翻合同必须包含正向 final_pitch_angle 下界（rad）、pitch_axis_error 无量纲上界、正值落地稳定性与站稳时长下界。net_pitch_target、pitch_rate_target、pitch_rate_sigma 已登记白名单，目标与尺度为正数；净旋转目标不低于验收目标，恢复与进度使用同一目标。圈数、时长与轴向误差范围仍须由任务设计记录依据或假设，不能据此声称必然可学习。

## 运行时保护与统计

training/front_flip_contract.py 编译前核对原始任务、目标对应表、全部门控与安全奖励，记录 front_flip_semantics。启动时复核任务、实际权重、硬约束和声明。轴向、权重或硬约束被篡改将拒绝启动。

只有完整审核的前翻配置，才在调用原生终止函数时临时屏蔽普通欧拉 roll/pitch 值，随后恢复真实姿态；原生接触、超时和全部非足端禁触继续执行。普通任务继续使用原生姿态终止。用户任务自己的姿态硬约束若冲突则编译前阻塞，不删除或放宽。contact_audit.json 与 rollout 元数据记录实际合同和处理策略，旧 checkpoint 不自动升级为新合同通过证据。

training/reward_statistics.py 保留全部原生物理重置，只汇总确实有采样的 episode。空 episode 不记录虚构零值或无穷极值；混合重置只汇总有数据的环境。真实采样产生的 NaN/Inf 继续暴露，不能被修复掩盖。
