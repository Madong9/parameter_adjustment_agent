# 验收、恢复与 Provider 可靠性修复

本次修改不改变 PPO 算法、不降低验收阈值、不把 Mock 或环境健康检查升级成动作验证通过。

## 验收证据

- 同步起跳由实际四足离地时序计算，取完整腾空事件中的最差时间差；落地俯仰由腾空结束首帧测量，取最差绝对值。不再使用固定 `0` 和 `0.03`。
- 无完整离地/落地、缺少足端或姿态数据、存在异常重置时，跳跃指标为未知，不能通过。
- `nan_count` 递归检查关节、动作、力矩、足端等嵌套数组中的 NaN、Inf 和显式空值。关节与力矩越限从轨迹携带的真实模型限位计算。
- 硬限位来自实际 Isaac Gym actor 的 DOF `lower/upper/effort` 属性；环境按奖励配置收缩后的 `dof_pos_limits` 仅作为软限位，单独记录 `joint_soft_limit_violations`，不能混淆成硬安全违规。
- `nan_count`、关节越限、力矩越限、禁止碰撞和异常终止必须具备有限证据且为零。缺失、形状错误或非有限数据不得默认零。所有种子保守聚合，缺失不能被另一种子的好结果掩盖。
- 轨迹和奖励逐控制步记录，视频独立降采样；`video_frame` 关联画面，`sim_time` 表示物理时间。当前仍不是每个 PhysX 子步记录，高频接触脉冲需要未来增加子步传感记录。

旧轨迹没有限位证据时，重新验收不能通过，应重新采集 rollout，不可补写“零越限”。本次不会自动重新认证或删除历史已完成任务。

## 任务、筛选与恢复

TaskSpec 的原始指令、机器人和 task_id 强制绑定用户输入。奖励重新设计保留原 TaskSpec 和验收合同，不能借修复降低目标。

候选筛选按任务使用前/后腿姿态、侧翻、跳跃、转向或行走的原始奖励代理；代理仅用于筛选，不是完成证明。最终仍按全部 rollout 的数值指标与独立视觉验收。

恢复重新计算实际 `config.yaml` SHA-256，与编译记录及 manifest 核对。首次多种子完整训练必须为对应种子生成新 checkpoint；退出码零但无新文件也会停止，禁止回退旧冒烟策略。

同一 task_id 的训练、规划、恢复共享非阻塞 `.run.lock`，竞争请求在写状态/合同前被拒绝。每次运行有独立 UUID run_id 和候选目录；任务级摘要仍表示最近一次运行，不是完整的多运行历史索引。

## Provider 与奖励审查

JSON 修复和换会话均保留原始提示词（动作、机器人、环境）、Schema、错误回复与原附件。全部网页操作按浏览器 profile 加线程重入锁和跨进程文件锁，覆盖绑定、上传、发送、等待与关闭。同 profile 不同会话别名也串行执行；进程退出会释放锁，不同独立 profile 可并行。

锁不能保证网页可用：用户手动切换页面、验证码、扩展断开与浏览器崩溃仍可能导致 Provider 失败。

奖励候选独立审核，有通过项就保留训练；全被拒绝时将完整上下文、固定任务和逐候选意见回传 Reward Designer，最多重试 `reward_design_review_retries` 次（默认 2）。每次审查落盘 `reward_review_attempt_XX.json`，重新设计与模型调用记录到 `events.jsonl`。重试不占 PPO 或训练后修订预算，但占模型调用额度/时间。超过上限或 Provider 失败仍人工复核，不绕过审核。

`doctor` 检查实际角色组合；无角色使用百炼时不检查其密钥，单独 ChatGPT 配置不由豆包健康代替。Mock 不报告生产就绪。

## 记忆兼容性

生产检索先硬过滤机器人、环境与奖励注册表版本，再按相关性排序。环境版本来自机器人 URDF/XML、机器人/基础环境源码和观测/命令/终止接口；奖励版本来自注册表、评估指标和 Agent 奖励执行源码，不再使用单次奖励配置哈希代替环境版本。

当前指纹写入 `environment_compatibility.json`，晋升记忆时保存版本。语义升级只聚合同机器人同版本证据，反例也不能跨环境废除规则。未知版本旧记忆保留但不进入生产上下文，不猜版本后批量升级。

当前指纹尚未覆盖 PhysX 驱动、所有 mesh 字节和软件运行时，应在未来环境锁定中扩展。RAG 项目资料仍是只读参考，不是已验证记忆或动作可行证据。

## 部署与能力边界

默认奖励设计、诊断、修订、经验总结走 OpenCLI/ChatGPT，任务理解/视觉按配置使用豆包主备；百炼只是可选 Provider。`.env` 不上传。

`patches/unitree_numpy_compat.patch` 把 NumPy 声明统一为 `>=1.20,<2`。Python 3.8 当前验证版本 `1.24.4`，入口兼容旧 Isaac Gym 标量别名，不强制降级。已安装 Unitree 需刷新无依赖 editable 元数据，见 [补丁说明](../../patches/README.md)。版本范围不代表每个版本都做过完整物理认证。

通用动作的浮动基座、逆动力学、接触力与轨迹优化专用执行器尚未全部实现；缺后端保留 `INCONCLUSIVE`/能力报告。本次不以接口或离线测试宣称通用物理验证完整、长训练已收敛。

## 复验

在 `rl_agent` 目录和对应 Conda 环境执行：

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -o addopts=''
python -m compileall -q rl_training_agent tests
```

新增 `tests/test_reliability_fixes.py` 覆盖跳跃、嵌套非有限值、模型限位、缺失安全证据、控制步记录、换会话上下文/附件、跨进程锁、任务互斥、角色健康检查、业务审核重试、配置篡改、禁止旧 checkpoint 和记忆版本过滤。测试不会发送真实模型消息或执行 PPO 长训练。

## 本机验证记录（2026-10-03）

全量测试 **338 项通过**（包含 29 项新增回归），`compileall` 与 `git diff --check` 通过。未发送真实模型请求、未重跑 PPO 长训练。

使用历史 Go2 倒退行走策略做 2 秒真实 Isaac Gym rollout（不训练）：记录 100 条轨迹、100 条逐项奖励和 20 帧视频，控制步间隔约 0.02 秒，两个表的画面索引一致。硬关节越限、力矩越限、禁止碰撞、异常重置与非有限值计数均为零；另测到 3 个奖励软限位越界样本，单独作为诊断信息保留。速度误差约 0.128 m/s。

该短测试验证录制与限位计算接入，不是对全部种子、目标时长和视觉的联合认证，更不代表重新训练成功。Unitree 依赖元数据已无依赖刷新，`pip check` 无冲突，未更改 NumPy 等依赖版本。
